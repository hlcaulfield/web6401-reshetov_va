# Лабораторная работа 2

**Тема:** Разработка многостраничного статического веб-сайта.

## Описание проекта
Сайт представляет собой каталог и сравнительный обзор легковых автомобилей. Исходные файлы проекта размещены в директории `lab2/`.

### Структура проекта:
* `index.html` — главная страница сайта с кратким позиционированием и навигацией;
* `cars.html` — каталог автомобилей со структурированными карточками моделей и ссылками на внешние справочные ресурсы;
* `compare.html` — таблица сравнения характеристик и позиционирования представленных моделей;
* `about.html` — страница с общей концепцией проекта;
* `css/style.css` — централизованная таблица стилей оформления проекта;
* `images/` — графические материалы (изображения моделей).
