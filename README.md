# Лабораторная работа 2

**Тема:** Разработка многостраничного статического веб-сайта.

## Описание проекта
Сайт представляет собой каталог и сравнительный обзор легковых автомобилей. Исходные файлы проекта размещены в директории `lab2/`.

### Структура проекта:
* `index.html` — главная страница сайта с кратким позиционированием и навигацией;
* `cars.html` — каталог автомобилей со структурированными карточками моделей и ссылками на внешние справочные ресурсы;
* `compare.html` — таблица сравнения характеристик и позиционирования представленных моделей;
* `about.html` — страница с общей концепцией проекта;
* `css/style.css` — централизованная таблица стилей оформления проекта;
* `images/` — графические материалы (изображения моделей).


# Лабораторная работа 3

**Тема:** Основы JavaScript.

## Описание проекта
Лабораторная работа посвящена изучению базовых конструкций языка JavaScript, работы с функциями, рекурсией, замыканиями, а также базовыми структурами данных. Исходные файлы проекта размещены в директории `lab3/`.

### Структура проекта:
* `src/core.js` — файл с реализацией требуемого набора функций;
* `src/core.spec.js` — набор автоматических тестов для валидации корректности работы функций;
* `package.json` — конфигурационный файл проекта и используемые зависимости.

### Инструкция по запуску:
1. Перейти в каталог лабораторной работы:
   ```bash
   cd lab3
   ```
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Запустить модульные тесты:
   ```bash
   npm test
   ```
